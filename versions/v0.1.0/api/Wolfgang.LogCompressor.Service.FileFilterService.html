Applies date-based and pattern-based filters to a collection of files.

public IReadOnlyList<FileInfo> Apply(IEnumerable<FileInfo> files, int? olderThanDays, DateTime? minDateTime, DateTime? maxDateTime, IReadOnlyList<string>? includePatterns = null, IReadOnlyList<string>? excludePatterns = null)

Parameters

files IEnumerable<FileInfo>

The files to filter.

olderThanDays int?

If specified, only files last modified more than this many days ago (before local midnight that many days back) are included.

minDateTime DateTime?

If specified, only files modified on or after this date.

maxDateTime DateTime?

If specified, only files modified on or before this date.

includePatterns IReadOnlyList<string>

If non-empty, only files matching at least one pattern are included.

excludePatterns IReadOnlyList<string>

Files matching any pattern are excluded.

Returns

IReadOnlyList<FileInfo>

The filtered list of files.
