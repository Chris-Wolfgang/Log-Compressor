Applies a strongly-typed LoggingOptions to a Serilog Serilog.LoggerConfiguration in code. This replaces LoggerConfiguration.ReadFrom.Configuration(...) (which instantiates sinks by name via reflection) with an explicit, trim-safe configuration.
