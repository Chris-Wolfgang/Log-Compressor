Wolfgang.LogCompressor

Namespace Wolfgang.LogCompressor.Command

Classes

Bundle

Bundles all matching files into a single compressed archive.

Compress

Compresses files individually, producing one archive per source file.

Init

Parent init command that groups the configuration-file generators. It produces nothing itself — the starter files are generated by the InitCompress and InitBundle subcommands; invoking init with no subcommand shows help.

InitBundle

Generates a bundle configuration file.

InitCompress

Generates a compress configuration file.

SharedOptions

Base class providing shared CLI options for compression commands.
