CompressFilesAsync(IEnumerable<(Stream Stream, string EntryName)>, Stream, CancellationToken)

Compresses multiple files into a single archive. The sequence is enumerated lazily and the implementation takes ownership of each input stream, disposing it immediately after writing — so the caller can open one source at a time rather than holding every file handle open for the duration of a large bundle.
